# Microsoft Foundry capability and status register

**Review snapshot: 2026-09-16.** Scope: Foundry resource/project and current Agent Service guidance unless a row says otherwise. Enterprise recommendation: approve capabilities individually for the actual workload. Exceptions: [time-bound request](../templates/exception-request.md). All rows inherit this scope, review date, recommendation and exception process unless overridden.

## How to interpret this register

- **GA** / **Preview** / **Deprecated** are feature-specific Microsoft release states. **Verification required** means a release status or target configuration was not established; absence of a Preview label is not proof of GA.
- **Retirement scheduled** describes an announced lifecycle deadline, separately from release status. Revalidate retirement dates before planning migration.
- Sources were researched online and selected **primary Markdown bodies from public MicrosoftDocs repositories** were reviewed. Direct Learn retrieval failed in this environment; authenticated GitHub access to those documentation repositories was also unavailable. Public source review succeeded independently. Sources were mutable `main` snapshots, not commit-pinned release artifacts.
- Dates identified below as “source dated” are documentation `ms.date` metadata, **not release dates**. Published rendering, tenant rollout, service behavior, API/SDK compatibility, regional availability, and commercial terms were not deployment-tested.
- These links substantiate capability descriptions, not enterprise policy. Workload evidence must record actual resource type, new/classic experience, agent/runtime, deployment type, region, gateway tier, protocol, API/SDK versions, permissions, and acceptance tests.
